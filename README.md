# ✈️ Quetzal Air — Sistema Web de Gestión de Vuelos  
Interfaz moderna, responsiva y profesional para la gestión de vuelos, check-in, pagos y consultas.  
Diseñada con un estilo premium basado en glassmorphism, paleta azul corporativa y acentos dorados.

---

## 📌 Características principales

- 🔐 **Login premium** con diseño moderno y inputs blancos  
- 🏔️ **Pantalla de bienvenida** con montañas minimalistas y hero azul  
- 🔎 **Búsqueda de vuelos** con formularios claros y accesibles  
- 📋 **Resultados responsivos** con tablas adaptables  
- 🛄 **Check-in con modal animado**  
- 💳 **Pago con validación visual**  
- 📄 **Confirmación elegante** con icono de éxito  
- 📱 **Totalmente responsivo** (móvil, tablet y desktop)  
- 🎨 **Diseño unificado** con glassmorphism y botones dorados  

---

## 🧩 Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **Glassmorphism UI**
- **Responsive Design (Mobile-first)**
- **Google Fonts — Poppins**

## 🚀 Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.  
2. Abre **index.html** en tu navegador.  
3. Navega por las distintas secciones del sistema.

No requiere servidor ni backend.
